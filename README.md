# saturday-team-dinner（研究组周六聚餐）

研究组周六 potluck 聚餐的完整计划：为 8 人准备的一桌菜单（5 道荤菜 + 4 道素菜 + 1 道甜品 + 1 款饮品），菜谱来自《程序员在家做饭指南》(HowToCook)。

## 使用方式

- 每道菜的完整食材与分步做法见 [MENU.md](./MENU.md)。
- 仓库 Issues 中每道菜各有一个 issue，帮忙的同学各自认领一道（assign 自己即可）。
- 采购请看标题为 `Shopping list` 的 issue：全部菜品食材去重后的总清单。
